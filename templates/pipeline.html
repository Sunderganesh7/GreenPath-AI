🧠 Image Processing Pipeline

Visual representation of image preprocessing stages for machine learning

Original Image

Raw input image captured from camera or satellite. No processing is applied at this stage.

Grayscale Image

Converted to grayscale to remove color information and reduce computational complexity.

Preprocessed Image

Noise reduction and contrast enhancement applied. Image is prepared for machine learning analysis.

Edge / Feature Enhanced Image

Important edges and features are highlighted to help object detection and classification models.
